# SoundCloud Downloader

Расширение для Chrome, которое скачивает треки SoundCloud в **mp3** с тегами и обложкой.

## Возможности

- Оранжевая кнопка ⬇ рядом с каждым треком: на странице трека, в списках, плитках, очереди и плеере.
- Только mp3. Если у трека нет mp3-потока, звук перекодируется в mp3 (256 kbps) прямо в браузере.
- Теги ID3: название, исполнитель, альбом, номер трека, год, жанр, лейбл, ISRC, описание, ссылка и обложка 500×500.
- «Исполнитель - Песня» в названии разбирается на исполнителя и название.
- Плейлист скачивается в папку с его названием, треки нумеруются по порядку.
- Меню по клику на иконку:
  - скачать все песни исполнителя или все лайки;
  - сделать плейлист из песен исполнителя или из лайков;
  - объединить несколько своих (или лайкнутых) плейлистов в один;
  - прогресс текущей загрузки, пауза и остановка;
  - выбор папки для сохранения (⚙).

Треки с DRM и треки только для подписчиков Go+ не скачиваются.

## Установка

1. Скачайте репозиторий (Code → Download ZIP) и распакуйте, или сделайте `git clone`.
2. Добавьте mp3-энкодер [lamejs](https://github.com/zhuker/lamejs). Он нужен для треков без mp3-потока и не хранится в репозитории. В папке расширения выполните:

   ```bash
   npm pack lamejs@1.2.1 && tar -xzf lamejs-1.2.1.tgz package/lame.min.js && mv package/lame.min.js . && rm -r package lamejs-1.2.1.tgz
   ```

   В командной строке Windows (cmd):

   ```bat
   npm pack lamejs@1.2.1 && tar -xzf lamejs-1.2.1.tgz package/lame.min.js && move package\lame.min.js . && rmdir /s /q package && del lamejs-1.2.1.tgz
   ```

3. Откройте `chrome://extensions`, включите «Режим разработчика», нажмите «Загрузить распакованное» и выберите папку расширения.

## Тесты

## Важно

Скачивайте только то, на что у вас есть права: свои треки или треки, которые автор разрешил скачивать. Использование может нарушать правила SoundCloud.
