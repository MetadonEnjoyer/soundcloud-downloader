# Сторонние компоненты

## LAME / lamejs — `lame.min.js`

Расширение использует mp3-энкодер **LAME** в виде JavaScript-порта **lamejs** версии 1.2.1, чтобы перекодировать в mp3 треки, у которых нет готового mp3-потока.

- Сайт LAME: http://lame.sourceforge.net
- Исходный код lamejs: https://github.com/zhuker/lamejs (пакет npm `lamejs@1.2.1`)
- Лицензия: GNU Lesser General Public License (LGPL), текст: https://www.gnu.org/licenses/lgpl-3.0.html

`lame.min.js` подключается как отдельный файл и лежит в репозитории без изменений, в том виде, в каком он поставляется в пакете npm `lamejs@1.2.1`. Лицензия MIT этого проекта на него не распространяется.
